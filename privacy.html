We are committed to respecting user privacy and maintaining transparency regarding our data practices. ## 2. Information We Collect and Process Depending on the features and commands used, the Bot may process the following information: **Discord User Information** - Discord User IDs. - Usernames and display names when needed for commands. - Server membership and permissions relevant to Bot operations. **Server Information** - Discord Server IDs. - Channel IDs. - Server permissions and configuration information. **Command Information** - Slash-command inputs. - Announcement text provided by authorized users. - Moderation targets and reasons. - Other information voluntarily submitted through Bot interactions. **Technical Information** - Bot connection status. - Application errors and operational logs. - Technical information necessary to maintain Bot functionality. The current implementation does not require general access to the content of every message posted in a server. ## 3. How Information Is Used We process information to: - Execute requested Bot commands. - Verify permissions and administrative authorization. - Deliver announcements and command responses. - Perform authorized moderation actions. - Maintain service reliability and troubleshoot errors. - Protect the Bot and its users against abuse. We do not use Discord user information for unrelated advertising or sell personal information. ## 4. Messages posted through the Bot may remain in Discord channels until deleted through Discord's functionality. If additional persistent storage features are introduced, this Privacy Policy will be updated to describe the relevant data, retention periods, and deletion procedures. ## 5.
